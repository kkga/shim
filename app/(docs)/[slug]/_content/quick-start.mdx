## Introduction

Shim is a collection of pre-styled, accessible UI components built on
[React Aria Components](https://react-spectrum.adobe.com/react-aria/index.html).
Components are installed directly into your codebase—you own the code and can
customize styling and behavior to fit your needs.

This guide assumes you have a React project set up and covers the initial setup
of Shim in your project using the CLI. For more detailed instructions on manual
setup, refer to the [manual setup guide](/manual-setup).

---

## Set up

<Step title="Install Tailwind CSS">
  Shim requires Tailwind CSS for styling. Please follow the [official Tailwind
  installation guide](https://tailwindcss.com/docs/installation) for your
  framework before continuing.
</Step>

<Step title="Initialize Shim" code={`pnpm dlx @kkga/shim init`}>
  Shim provides a CLI to help set up your project. Run the following command in
  your terminal to initialize Shim.
  <br /> This creates a <strong>shim.config.json</strong> file in your project root
  that defines where components, utility files, and CSS are installed.
</Step>

<Step
  title="Configure path alias"
  code={[
    {
      title: "tsconfig.json",
      content: `
{
    "compilerOptions": {
        "baseUrl": ".",
        "paths": {
            "@/*": ["./*"]
        }
    }
}`,
    },
  ]}
>
  Shim components import files via the <strong>@/</strong> alias. <br />
  Configure the path in <strong>tsconfig.json</strong> (or <strong>
    jsconfig.json
  </strong>) so those imports resolve.
</Step>
