## Introduction

Shim is a collection of pre-styled, accessible UI components built on [React Aria Components](https://react-spectrum.adobe.com/react-aria/index.html).
Components are installed directly into your codebase—you own the code and can customize styling and behavior to fit your needs.

This guide covers the prerequisites and setup steps to get Shim running in your React project.

## Install the prerequisites

Shim components depend on several libraries. Use the commands below to install them.

<Step title="React Aria Components" code="pnpm add react-aria-components">
  Core unstyled primitives used by Shim components.
  Read the docs at
  [react-spectrum.adobe.com/react-aria/components](https://react-spectrum.adobe.com/react-aria/components.html).
</Step>

<Step title="Tailwind CSS v4">
  Utility-first styling foundation.<br />
  Installation depends on your framework—follow the
  [official Tailwind guide](https://tailwindcss.com/docs) for the
  correct steps.
</Step>

<Step title="tailwind-variants" code="pnpm add tailwind-variants">
  Declarative Tailwind [variant helpers](https://www.tailwind-variants.org/).
</Step>

<Step title="Radix Colors" code="pnpm add @radix-ui/colors">
  Semantic color palette used by Shim tokens.<br />
  Browse palettes at [radix-ui.com/colors](https://www.radix-ui.com/colors).
</Step>

<Step title="Phosphor Icons" code="pnpm add @phosphor-icons/react">
  Icon set referenced by several components. <br />
  Explore the catalog at [phosphoricons.com](https://phosphoricons.com).
</Step>
