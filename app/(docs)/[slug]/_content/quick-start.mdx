## Introduction

Shim is a collection of pre-styled, accessible UI components built on [React Aria Components](https://react-spectrum.adobe.com/react-aria/index.html).
Components are installed directly into your codebase—you own the code and can customize styling and behavior to fit your needs.

This guide covers the prerequisites and setup steps to get Shim running in your React project.

</section>
