## Overview

Many Shim components support theming options like size and visual variants to help you adapt the look and feel to your design needs.
You can also set global defaults using a theme provider to ensure consistency across your application.

***

## Size

Most components support four sizes that scale proportionally.

## Variants

### Field variants

Forms and field-based components support "classic", "soft", and "outline" variants that adjust visual styles while preserving spacing and layout.

<ComponentDemo component="theme" demo="field-variant" demoClassName="grid sm:grid-cols-3 gap-8" codeTitle="Field variants example" stacked />

### Button variants

Buttons support "soft", "ghost", and "solid" variants for different visual emphasis levels.
Note that ToggleButton and ToggleButtonGroup do not support the "solid" variant to avoid confusion with selected states.

## Set global defaults

Wrap your application (or any subtree) in the `<Theme>` provider to broadcast shared props to every Shim component underneath it.
The provider merges values from the nearest ancestor, so you can layer overrides as needed.

```tsx title="layout.tsx"
import type { ReactNode } from "react";
import { Theme } from "@/shim-ui/lib/theme";
import "./globals.css";

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en">
      <body>
        <Theme fieldVariant="soft" labelPosition="side" size={2}>
          {children}
        </Theme>
      </body>
    </html>
  );
}
```

Inside a page or component you can scope a more specific override while inheriting the rest of the defaults:

```tsx title="components/callout.tsx"
import { Theme } from "@/shim-ui/lib/theme";
import { Button } from "@/shim-ui/button";

export function Callout() {
  return (
    <Theme buttonVariant="solid">
      {...}
      <Button>Get started</Button>
      <Button>Learn more</Button>
    </Theme>
  );
}
```
