## Overview

Use the Shim CLI to initialize configuration and install components with their
dependencies directly into your project.

---

## Usage

Run commands on demand via **pnpm dlx** (no local install required):

```bash title="Initialize Shim and add components"
pnpm dlx @kkga/shim init
pnpm dlx @kkga/shim add button dialog form
```

**Tip:** Add a script to your **package.json** for shorter commands:

```json title="package.json"
{
  "scripts": {
    "shim": "pnpm dlx @kkga/shim"
  }
}
```

```bash title="Then run"
pnpm shim init
pnpm shim add button dialog form
```

## Commands

### shim init

Initialize Shim in your project. Automatically installs required dependencies,
creates the configuration file, and installs utility and CSS files.

- Checks if **Tailwind CSS** is installed (required prerequisite)
- Installs all required dependencies (**react-aria-components**,
  **tailwind-variants**, **tailwind-merge**, **@radix-ui/colors**,
  **@phosphor-icons/react**)
- Creates a **shim.config.json** configuration file
- Downloads required utility files (**style.ts**, **theme.tsx**) to your utils
  directory
- Downloads CSS theme file (**theme.css**) to your styles directory
- Ensures your project is ready for component installation

```bash title="Terminal"
shim init [options]
```

### shim add

Install one or more components by name. Automatically installs component
dependencies.

```bash title="Terminal"
shim add <components...> [options]
```

## Features

- Import transformation: component import paths are rewritten based on your
  configured destinations.
- Dependency resolution: component dependencies are installed automatically.
- Utility management: `style.ts`, `theme.tsx`, and `theme.css` are created and
  kept in your chosen directories.

---

## Examples

```bash title="Initialize with defaults"
pnpm dlx @kkga/shim init
```

```bash title="Initialize with custom paths"
pnpm dlx @kkga/shim init \
  --components-path src/ui \
  --utils-path src/lib \
  --css-path src/styles
```

```bash title="Install components"
pnpm dlx @kkga/shim add button dialog form
```

```bash title="Install to a different directory"
pnpm dlx @kkga/shim add button --path src/features/ui
```

```bash title="Overwrite existing files"
pnpm dlx @kkga/shim add dialog --overwrite
```

```bash title="Use a package script"
# package.json: { "scripts": { "shim": "pnpm dlx @kkga/shim" } }
pnpm shim add button
```

## Configuration File

Running **shim init** creates a configuration file in your project root:

```json title="shim.config.json"
{
  "componentsPath": "components",
  "utilsPath": "utils",
  "cssPath": "styles"
}
```

## Troubleshooting

### Tailwind CSS is not installed

`shim init` requires Tailwind CSS to be installed. If you see this error,
install and configure Tailwind first:

```bash
pnpm add -D tailwindcss postcss autoprefixer
pnpm tailwindcss init -p
```

See the [Tailwind installation guide](https://tailwindcss.com/docs/installation)
for framework-specific setup.

### Component not found

If you get a "component not found" error, check your spelling. To see available
components, visit the [components](/components) section or check the
[registry](https://github.com/kkga/shim/blob/master/shim-ui/registry/registry.json).

### Files already exist

Use `--overwrite` (for `add`) or `--force` (for `init`) to replace existing
files:

```bash
pnpm dlx @kkga/shim add button --overwrite
pnpm dlx @kkga/shim init --force
```

### Invalid path error

Paths should be relative to your project root (where `package.json` is):

```bash
# ✓ Good
pnpm dlx @kkga/shim init --components-path src/components

# ✗ Bad (absolute filesystem path)
pnpm dlx @kkga/shim init --components-path /Users/name/project/src/components
```
